## 2. 사람·계정·역할

| 표준어 | 코드 이름 | 뜻 | 비고 |
|---|---|---|---|
| 계정 | `User` | 로그인하는 사람 한 명. 로그인 수단(소셜 식별값, 애플 연결 해지용 토큰은 암호화 저장), 알림용 기기 토큰(`DeviceToken`), 이용약관 동의 기록(`TermsConsent`)만 가집니다 | 학원을 옮겨도 유지됩니다. 학생 이름·생년월일은 계정이 아니라 소속에 있습니다 |
| 기기 토큰 | `DeviceToken` (`type = APP / WEB`, `platform`) | 알림을 받을 기기·브라우저의 토큰 | 앱 푸시와 웹 푸시를 둘 다 받을 수 있어 종류를 나눕니다 |
| 소속 | `Membership` | 계정과 학원의 연결. 역할, 학생 정보(이름·학년·생년월일·학교명), 상태를 담습니다 | 한 계정이 여러 학원에 소속될 수 있습니다. 데이터 접근은 소속을 통해서만 합니다 |
| 역할 | `MembershipRole { DIRECTOR, TEACHER, STUDENT, GUARDIAN }` (테이블 `membership_roles`) | 소속 안에서의 자격 | 한 소속에 역할을 여러 개 둘 수 있습니다(예: 원장 겸 선생님) |
| 원장 | `DIRECTOR` | 학원 관리자. 웹만 씁니다 | 숙제·수행 기록·메모는 고칠 수 없습니다(메모는 삭제만 가능). 담당 배정·학생 정보·주의 학생 처리 상태는 고칠 수 있습니다 |
| 선생님 | `TEACHER` | 숙제를 내고 수행 기록을 남기는 사람. 웹(상세 작업)과 앱(확인·알림·일괄 확정)을 씁니다 | 표준어는 "선생님"입니다. 기존 문서의 "강사"와 같은 사람입니다 |
| 학생 | `STUDENT` | 숙제를 받고 사진을 제출하는 사람. 앱을 씁니다 | |
| 보호자 | `GUARDIAN` | 학생의 부모 등. 계정 역할과 법무 문서에서는 "보호자"라고 부릅니다 | 기능 이름에서는 "학부모"(학부모 열람, 학부모 앱)를 그대로 씁니다. 같은 사람입니다 |
| 법정대리인 | — | 만 14세 미만 학생 대신 동의하는 보호자(법률 용어) | 14세 미만 흐름은 정식 단계에서 엽니다 |
| 담당 선생님 / 담당 배정 | `TeacherAssignment` | 학생에게 배정된 선생님. **학생 단위로** 배정하고 한 학생에 여러 명 둘 수 있습니다(예: 과목별) | 비담당 차단, 미기록 알림, 대강의 기준입니다. 대강·보강은 원장이 담당을 추가해서 처리하고, 따로 "예외 권한"은 없습니다 |
| 책임 선생님 | `responsible_teacher_id` (→ `memberships.id`) | 그 숙제를 낸 담당 선생님. 그 숙제의 수행 기록을 고칠 수 있는 유일한 사람입니다 | 담당이 바뀌면 미확정 기록만 새 담당에게 넘어갑니다 |
| 비담당 선생님 | — | 같은 학원이지만 그 학생의 담당이 아닌 선생님 | 그 학생의 데이터를 볼 수 없습니다 |
| 초대 링크 | `Invitation` (`token_hash`, `first_invited_at`, `expires_at`) | 학원이 학생·선생님을 들이기 위해 발급하는 1회용 링크 | 미동의 14일 삭제는 `first_invited_at` 기준입니다. 옛 기획의 "초대코드"는 쓰지 않습니다 |
| 원장 승인 | `approval` | 초대 링크로 가입한 사람이 그 학생·선생님이 맞는지 원장이 확인하고 활성화하는 단계 | |
| 소속 상태 | `MembershipStatus { INVITED, PENDING_APPROVAL, ACTIVE, SUSPENDED, ENDED }` | 초대됨 → 승인 대기 → 활성 / 정지 / 끝남 | 퇴원·동의 철회·학원 해지·파일럿 종료가 모두 "끝남 → 삭제 예약"이라 상태를 하나로 두고 사유를 따로 남깁니다 |
| 종료 사유 | `MembershipEndReason { CONSENT_WITHDRAWN, LEFT, ACADEMY_TERMINATED, PILOT_ENDED, RECONSENT_EXPIRED }` (`end_reason`) | 소속이 끝난 이유 | `LEFT`는 퇴원(학생)과 퇴사(선생님)를 함께 뜻합니다 |
| 재동의 기한 | `reconsent_due_at` | 만 14세가 된 학생의 본인 재동의 기한 | 유예 60일 동안은 `ACTIVE` 상태입니다 |
| 삭제 예정 | `delete_scheduled_at` | 소속이 끝나 삭제가 예약된 시각 | 삭제 대기 중에 다시 등록하면 삭제는 그대로 진행하고 새 소속을 만듭니다 |
| 퇴원 | `LEFT` (학생) | 학생이 학원을 그만두는 것 | 백업까지 포함해 30일 안에 그 학원의 학생 데이터를 삭제합니다 |
| 퇴사 | `LEFT` (선생님) | 선생님이 학원을 그만두는 것 | 퇴사 처리 화면에 "기록 안 한 숙제 n건 — 담당을 먼저 바꾸세요" 경고를 띄웁니다 |
| 반 | `ClassGroup` (테이블 `class_groups`) | 학생을 묶는 수단. 필수 개념이 아닙니다 | v1.3. 반에 선생님을 지정하면 소속 학생에게 담당이 일괄 배정됩니다. 한 학생이 여러 반에 속할 수 있습니다. Java의 `Class`와 겹쳐 `ClassGroup`으로 씁니다 |

| 마감 | `due_at` | 숙제 제출 기한. 기본 23:59, 학원이 **09:00~23:59** 안에서 바꿀 수 있습니다 | |
| 마감 여유 | `grace_period` | 마감 전에 제출을 시작했으면 **마감 후 10분** 안에 업로드가 끝난 것까지 인정합니다 | 시작 시각은 서버가 제출 요청을 받은 시각입니다 |

| 제출 사진 | `SubmissionPhoto` (`object_key`, `delete_after`) | 학생이 올린 숙제 사진. 학생 → 선생님 단방향이고 다른 학생은 볼 수 없습니다 | 마감 전에만 교체할 수 있고, 교체하면 이전 사진은 즉시 삭제합니다 |
| 수행 기록 | `PerformanceRecord` | 선생님이 판단한 숙제 수행 여부 | 제출과는 다른 값입니다. 이행률과 주의 학생 판정은 수행 기록으로 계산합니다 |
| 수행 결과 | `PerformanceResult { COMPLETE, PARTIAL, INCOMPLETE, EXEMPT }` | 수행 기록의 값: **완료 / 일부 / 미완료 / 면제** | |
| 제안 / 확정 | `RecordState { PROPOSED, CONFIRMED }` | 수행 기록의 상태. 마감 + 10분 뒤 시스템이 미리 채운 값은 "제안", 선생님이 확인하면 "확정" | 미리 채우기: 사진 냄 → 완료, 안 냄 → 미완료 |
| 미기록 | — | 값이 아니라 상태입니다. **아직 확정하지 않은 기록**(제안 상태) 또는 미리 채우기 전이라 기록이 없는 경우 | 미기록 알림은 확정되지 않은 기록의 개수를 셉니다 |
| 일괄 확정 | — | 여러 학생의 제안 값을 한 번에 확정하는 기능 | **사진을 낸 학생에게만** 적용합니다(서버에서 강제). 선생님 앱에서도 됩니다 |
| 수정됨 | — | 확정한 기록을 고쳤다는 표시. 언제, 무엇에서 무엇으로 바뀌었는지 이력이 남습니다 | 고칠 수 있는 사람은 책임 선생님뿐입니다 |
| 기록률 | `record_rate` | 마감 + 10분(미리 채우기)이 지난 기록 중 선생님이 확정한 비율(면제 포함) | 선생님별로는 기록률만 보여주고 비교·순위는 두지 않습니다 |
| 이행률 | `completion_rate` | 학생이 숙제를 얼마나 해 왔는지의 비율 | 계산식 추천안: (완료 × 1 + 일부 × 0.5) ÷ 확정된 평가 대상 건수. **아직 확정 전**입니다 |
| 미기록 알림 | — | 마감 24시간 뒤부터 하루 한 번 선생님에게 "미기록 n건"을 알리는 것 | |
| 학습지 | `Worksheet` | 시판 교재가 아닌 프린트 숙제. 교재 DB에 넣지 않고 숙제를 낼 때 자유 텍스트로 적습니다 | 파일 업로드는 v1.3, 숙제마다 별도 파일, 숙제 마감 후 30일에 자동 삭제 |

## 10. 쓰지 않는 말

| 쓰지 않는 말 | 대신 쓰는 말 | 이유 |
|---|---|---|
| 과제 | 숙제 | 같은 개념을 두 말로 부르지 않기 위해(검토 E-08) |
| 알림장 | (서비스 설명에서 쓰지 않음) | 옛 정체성("카톡 대체 알림장") |
| 강사 | 선생님 | 표준어 통일. 기존 문서의 "강사별"은 "선생님별"과 같은 뜻 |

| 초대코드 | 초대 링크 | 가입은 1회용 링크 방식 |
